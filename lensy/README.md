# Lensy 👁️ – υπενθύμιση φακών επαφής

Εφαρμογή Android που θυμάται πότε έβαλες τους φακούς επαφής σου και σε ειδοποιεί πριν λήξουν.

## Τι κάνει

- Διαλέγεις τύπο φακών (2 εβδομάδων, μηνιαίοι, 3 μηνών ή δικό σου διάστημα) και πότε τους έβαλες.
- Ένα κουμπί «Έβαλα καινούργιους φακούς» ξεκινά νέο κύκλο.
- Ειδοποιήσεις 2 μέρες πριν, 1 μέρα πριν, την ημέρα αλλαγής και κάθε μέρα όσο καθυστερείς, στην ώρα που ορίζεις (προεπιλογή 09:00).
- Ο χαρακτήρας-μάτι κουράζεται και κοκκινίζει όσο παλιώνουν οι φακοί.
- 12 γλώσσες: Αγγλικά, Ελληνικά, Ισπανικά, Γερμανικά, Γαλλικά, Ιταλικά, Πορτογαλικά, Τουρκικά, Ρωσικά, Ιαπωνικά, Κορεατικά, Κινέζικα.
- Δωρεάν δοκιμή 40 ημερών. Μετά οι ειδοποιήσεις σταματούν μέχρι την εφάπαξ αγορά «espresso» (0,99 €). Η αντίστροφη μέτρηση συνεχίζει να φαίνεται.
- Όλα τα δεδομένα μένουν στο κινητό. Δεν υπάρχει λογαριασμός ούτε διαφημίσεις.

## Build

Άνοιξε τον φάκελο `lensy/` στο Android Studio, ή από τερματικό:

```
./gradlew testDebugUnitTest assembleDebug
```

Το APK βγαίνει στο `app/build/outputs/apk/debug/`. Κάθε push που αλλάζει τον φάκελο `lensy/` χτίζει το ίδιο APK στο GitHub Actions (workflow «Lensy Android build») και το ανεβάζει ως artifact `lensy-debug-apk`.

## Δομή κώδικα

| Αρχείο | Ρόλος |
|---|---|
| `core/Logic.kt` | Υπολογισμοί: ημέρα αλλαγής, επόμενη υπενθύμιση, διάθεση χαρακτήρα, δοκιμή. Καλύπτεται από `LogicTest`. |
| `data/Store.kt` | Αποθήκευση ρυθμίσεων στο κινητό (DataStore). |
| `reminders/Reminders.kt` | Προγραμματισμός ειδοποιήσεων, επαναφορά μετά από επανεκκίνηση. |
| `billing/Billing.kt` | Εφάπαξ αγορά μέσω Google Play Billing. |
| `ui/` | Οθόνες (Compose), χαρακτήρας-μάτι, δακτύλιος, κομφετί. |
| `res/values-*/strings.xml` | Μεταφράσεις. |

## Τι μένει για την κυκλοφορία στο Play Store

1. Λογαριασμός Google Play Developer (25 $ εφάπαξ).
2. Νέα εφαρμογή στο Play Console με package `com.arch1based.lensy`, τιμή **Δωρεάν**.
3. Προϊόν εντός εφαρμογής (one-time product) με id **`lensy_espresso`** και τιμή 0,99 €. Το id πρέπει να είναι ακριβώς αυτό, αλλιώς το κουμπί αγοράς δεν κάνει τίποτα.
4. Κλειδί υπογραφής και release build (`./gradlew bundleRelease`) για ανέβασμα `.aab`.
5. Κλειστή δοκιμή με δοκιμαστές πριν από τη δημόσια κυκλοφορία, όπως ζητά η Google για νέους προσωπικούς λογαριασμούς.
6. Καταχώριση καταστήματος: στιγμιότυπα οθόνης, εικονίδιο 512×512, πολιτική απορρήτου (η εφαρμογή δεν συλλέγει δεδομένα).

Η αγορά δεν μπορεί να δοκιμαστεί πριν ανέβει η εφαρμογή στο Play Console. Τα υπόλοιπα δουλεύουν με το debug APK.

## Κείμενα καταστήματος

Το όνομα συνοδεύεται από περιγραφικές λέξεις ώστε να βρίσκεται στην αναζήτηση. Το όριο τίτλου είναι 30 χαρακτήρες.

| Γλώσσα | Τίτλος | Σύντομη περιγραφή |
|---|---|---|
| Ελληνικά | Lensy: Υπενθύμιση φακών επαφής | Μην ξεχνάς ξανά πότε να αλλάξεις φακούς επαφής. Ο Lensy το θυμάται για σένα. |
| English | Lensy: Contact Lens Reminder | Never forget when to change your contact lenses. Lensy remembers for you. |

## Ιδέες για επόμενη έκδοση

Widget αρχικής οθόνης, απόθεμα ζευγαριών, ξεχωριστή παρακολούθηση για κάθε μάτι.
